# 👻 Ghost HQ

Ghost HQ is a Windows desktop app that brings a collection of tiny animated ghosts to life on your desktop.

Each ghost has its own personality and behaviour. Some peacefully wander around, some follow your mouse, some fall asleep, and some cause absolute chaos.

## 👻 Meet the Ghosts

### 🚶 Wanderer
A peaceful little ghost that wanders around your desktop.

### 🖱️ Follower
Follows your mouse cursor around the screen.

### 😴 Sleeper
Wanders around until it gets tired and falls asleep.

### 💨 Zoomer
Usually behaves normally... until it suddenly gets the zoomies.

### 💥 Bumper
Searches for other ghosts, chases them down, and sends them flying.

Be warned: there is a very small chance that Bumper becomes considerably more dangerous.

### 🦄 Unighost
A magical ghost that teleports around your desktop in a rainbow poof.

## ✨ Features

- Multiple animated desktop ghosts
- Different personalities and behaviours
- Spawn and remove ghosts whenever you want
- Ghost-to-ghost interactions
- Multi-monitor support
- Bumper chasing and collisions
- Unighost teleport effects
- Simple Ghost HQ control panel

## 📥 Download

You do **not** need Python or any programming software to play with Ghost HQ.

1. Open the **Releases** section of this repository.
2. Select the latest release.
3. Download the Windows ZIP.
4. Extract the ZIP.
5. Double-click `GhostHQ.exe`.
6. Enjoy your new desktop inhabitants. 👻

> Ghost HQ is currently designed for Windows.

## ⚠️ Windows Security Warning

Windows may display a SmartScreen warning when opening Ghost HQ for the first time because the application is independently developed and is not digitally signed.

Only run the application if you downloaded it from this repository.

## 🖥️ Multi-Monitor Support

Ghost HQ can run ghosts on:

- Monitor 1
- Monitor 2
- Both monitors
